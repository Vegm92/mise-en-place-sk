# 06 · Guías de entrevista: 10 hosteleros y 5 gestorías

**Contexto.** El issue #783 pedía exactamente esto (5 gestorías + 10 hosteleros) y se cerró el 8 de septiembre de 2026 como «no planificado»: la hipótesis de que el 30 % de las altas del año 1 vendrán por gestorías sigue sin validar. Estas guías permiten hacerlo **en paralelo a la venta**, con dos condiciones:

1. **Una entrevista no es una demo.** No se enseña el producto ni se habla de precio hasta que terminan las preguntas. Si el entrevistado pregunta «¿y tú qué vendes?», se contesta en una frase y se aplaza: «Se lo cuento al final, que si no le condiciono».
2. **Pasado, no hipótesis** (método *The Mom Test*). Prohibido: «¿usaría…?», «¿pagaría…?», «¿le parecería útil…?». Permitido: «¿qué hizo la última vez que…?», «¿cuánto le costó…?», «¿qué ha probado…?».

**Duración:** 20–25 min. **Formato:** presencial en el local (fuera de servicio) o videollamada. **Notas:** literales, con comillas. Pedir permiso para grabar; si dicen que no, una segunda persona toma notas o se escribe justo al terminar.

---

## Parte A · Hosteleros (10 entrevistas)

### A.1 Filtro (antes de agendar, 2 minutos por teléfono o mensaje)

| Pregunta | Entra si… |
|---|---|
| ¿Cuántos locales tiene? | 1–10 |
| Más o menos, ¿cuánto compran al mes a proveedores? | ≥ 10.000 € (para estas entrevistas se abre algo el ICP para aprender; para venta, ≥ 20.000 €) |
| ¿Quién recibe y quién revisa las facturas de proveedor? | El entrevistado es uno de los dos, o decide sobre ello |
| ¿Forma parte de una cadena o franquicia con compras centralizadas? | No |

**Mezcla objetivo de las 10:** 3 locales únicos de alto volumen o alta gama · 4 grupos de 2–5 locales · 3 grupos de 6–10. Al menos 3 con cocina de pescado/marisco.

### A.2 Apertura (1 min)

> «Gracias. No vengo a venderle nada hoy: estoy intentando entender cómo gestionan los restaurantes de Barcelona las facturas y los precios de los proveedores. No hay respuestas buenas ni malas; lo que más me sirve es que me cuente cosas que hayan pasado de verdad.»

### A.3 Preguntas (elegir 12–15; las marcadas ★ no se saltan)

**Recorrido del papel**
1. ★ «Cuénteme qué pasó con el último albarán que llegó: quién lo recibió, qué hizo con él y dónde está ahora.»
2. «¿Y con la factura de esa misma entrega? ¿Cuándo llegó y quién la miró?»
3. ★ «¿Cuánto tiempo dedicaron la semana pasada a facturas y albaranes? ¿Quién?»

**Precios**
4. ★ «La última vez que un proveedor les subió un precio, ¿cómo se enteraron? ¿Cuánto tiempo después de la subida?»
5. ★ «¿Qué hicieron entonces? (renegociar, cambiar de proveedor, subir carta, nada)»
6. «¿De qué producto fue? ¿Cuánto compran al mes de ese producto?» *(Con esto el entrevistado calcula solo lo que le costó; no lo calcule usted.)*

**Errores**
7. ★ «¿Recuerda la última vez que encontraron un error en una factura: algo cobrado de más, una entrega incompleta, una factura repetida? ¿Cómo lo vieron? ¿Qué pasó después?»
8. «¿Cuántas veces ha pasado este año, más o menos?»

**Lo que ya intentaron**
9. ★ «¿Han intentado alguna vez controlar los precios de compra de forma sistemática (Excel, un programa, alguien de oficina)? ¿Qué pasó? ¿Por qué lo dejaron o por qué sigue?»
10. «¿Qué programas usan hoy para gestionar el restaurante? ¿Cuánto pagan por ellos? ¿Por qué ese y no otro?»
11. «La última herramienta que dejaron de usar, ¿por qué la dejaron?»

**Dinero y decisión**
12. ★ «¿Cuánto compraron a proveedores el mes pasado? ¿De dónde sale ese número: de la gestoría, del banco, de una hoja?»
13. «Cuando han comprado un programa para el restaurante, ¿quién lo decidió y cuánto tardaron en decidir?»

**Gestoría (enlaza con la Parte B)**
14. ★ «¿Qué le mandan a su gestoría, cómo y cada cuánto? ¿Le ha recomendado alguna vez algún programa?»

**Multi-local (solo grupos)**
15. «¿Comparan lo que paga cada local por el mismo producto? ¿Cuándo fue la última vez? ¿Qué descubrieron?»

**Cierre**
16. ★ «¿Con quién más debería hablar? ¿Me presentaría a alguien?»
17. «Si le enseño lo que estoy haciendo con tres facturas suyas, ¿me las mandaría?» *(Es una petición de compromiso, no una pregunta de opinión.)*

### A.4 Señales de que pagaría (anotar sí/no en cada una)

| Señal | Peso |
|---|---|
| Cuenta un incidente concreto y reciente con € (subida o error) | Alta |
| Ya dedica tiempo o dinero a una solución casera (Excel, persona de oficina) | Alta |
| Ya paga por algún software de gestión del restaurante | Media |
| Da su cifra de compra mensual sin dudar | Media |
| **Acepta un siguiente paso con coste para él**: manda facturas, agenda piloto, presenta a un socio o a su gestoría | **Decisiva** |
| Pregunta por el precio o por cuándo puede empezar, sin que usted lo saque | Alta |

**Señales de que no:** «estaría bien», «cuando lo tengáis me avisas», ningún incidente concreto, no sabe cuánto compra, no hay nadie que mire facturas y no le preocupa.

## Parte B · Gestorías (5 entrevistas)

**Lo que hay que averiguar** (de `docs/onboarding/marketing/03_canales/gestorias.md`): si el tecleo es **ingreso** o **coste** para el despacho; si ya tienen acuerdo con Holded, Quipu u otros; qué formato necesitan (hoy exportamos Excel, no a3 ni Contasol); y si les sirve algo que viene del albarán, cuando su documento es la factura.

**Lo que no se dice nunca:** nada que suene a llevar la contabilidad, hacer impuestos o quitarles el cliente.

### B.1 Filtro

| Pregunta | Entra si… |
|---|---|
| ¿Cuántos clientes de hostelería llevan? | ≥ 5 |
| ¿Quién contabiliza las facturas de proveedor de esos clientes? | El despacho (no el cliente) |
| ¿Qué programa contable usan? | Cualquiera; anotarlo |
| ¿Tamaño del despacho? | Mezclar: 2 pequeños (≤ 5 personas), 2 medianos, 1 grande |

**Cómo encontrarlas:** preguntar a cada hostelero entrevistado o en piloto «¿qué gestoría lleva sus cuentas?» y pedir presentación. Una gestoría presentada por su cliente es mucho más fácil que una en frío.

### B.2 Apertura

> «Gracias. Estoy hablando con despachos que llevan restaurantes para entender cómo les llega la documentación y qué trabajo les da. No vengo a ofrecer nada que haga lo que hacen ustedes.»

### B.3 Preguntas (12–15; ★ no se saltan)

**Cómo llega el papel**
1. ★ «Piense en su cliente de hostelería más grande. ¿Cómo le llegó el mes pasado la documentación de proveedores: papel, email, fotos por WhatsApp, una carpeta compartida?»
2. ★ «¿Qué hicieron con ella, paso a paso? ¿Quién lo hizo y cuánto tardó?»
3. «¿Contabilizan las facturas de proveedor por total o por línea?»
4. «¿Qué hacen con los albaranes, si les llegan?»

**Economía del despacho (la pregunta que decide el canal)**
5. ★ «¿Ese trabajo de introducir facturas lo cobran aparte o va dentro de la cuota? ¿Cómo calculan la cuota de un cliente de hostelería?»
6. «¿Qué cliente de hostelería les da más trabajo por euro que cobran? ¿Por qué?»
7. «¿Cuántas veces el último trimestre tuvieron que perseguir a un cliente para que mandara papeles?»

**Herramientas y formatos**
8. ★ «¿Qué programa contable usan? ¿Han importado alguna vez facturas desde un fichero? ¿De qué herramienta y en qué formato? ¿Funcionó?»
9. «¿Algún cliente les manda ya los datos desde un programa propio? ¿Qué pasó con eso?»

**Recomendación**
10. ★ «¿Han recomendado algún programa a un cliente en el último año? ¿Cuál, por qué y qué pasó después?»
11. ★ «¿Tienen acuerdo con algún proveedor de software (Holded, Quipu, a3, otro)? ¿Cómo empezó? ¿Qué reciben a cambio, si reciben algo?»

**Costes de compra del cliente**
12. «¿Algún cliente les ha pedido ayuda para entender por qué le sube el coste de materia prima? ¿Qué hicieron?»

**Normativa**
13. «¿Qué les han preguntado sus clientes de hostelería sobre VERI\*FACTU o la factura electrónica? ¿Qué les contestaron?»

**Confianza**
14. «La última vez que un cliente empezó a usar un programa que les afectaba a ustedes, ¿qué salió bien y qué salió mal?»

**Cierre**
15. ★ «¿Con qué otro despacho debería hablar? ¿Y me presentaría a uno de sus clientes de hostelería?»

### B.4 Señales

| Señal | Qué significa |
|---|---|
| El tecleo va dentro de la cuota y les come margen | **Dolor**: canal posible |
| Cobran por documento o por hora de introducción | **Riesgo**: les quitamos ingresos; el canal no funciona así |
| Ya han importado ficheros de otra herramienta | Lo técnico es viable; anotar formato exacto |
| Piden a3/Contasol/Sage como condición | Hueco de producto, no de marketing |
| Han recomendado software y cobran comisión | El modelo partner tiene precedente con ellos |
| **Presentan a un cliente de hostelería** | **Decisiva** |
| «Que el cliente use lo que quiera, a mí me da igual» | Indiferencia: canal débil |

### Síntesis conjunta (al terminar las 15)

| Hipótesis | Evidencia a favor (nº entrevistas) | En contra | Decisión |
|---|---|---|---|
| El dueño se entera tarde de las subidas de precio | | | |
| Hay errores de factura frecuentes y con € relevantes | | | |
| Excel es la alternativa real (no otro software) | | | |
| El umbral de 20.000 €/mes separa a quien paga de quien no | | | |
| Los grupos quieren comparar locales (hoy no hay vista consolidada) | | | |
| La gestoría cobra el tecleo dentro de la cuota (canal viable) | | | |
| La gestoría necesita a3/Contasol para que le sirva | | | |
| Alguna gestoría presentaría clientes | | | |

**Regla de decisión:** una hipótesis se da por buena con ≥ 6 de 10 hosteleros (o ≥ 3 de 5 gestorías) **con un hecho concreto**, no con una opinión. Si el canal gestorías no llega a 3 de 5, actualizar el supuesto del 30 % del plan de negocio (§9), como pedía #783.
