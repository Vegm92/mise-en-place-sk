# Incidencias y cosas a revisar

Cosas detectadas al revisar contenido o producto que **todavía no son una
decisión** — cuando se resuelvan, la respuesta va a `06_decisiones/` como MDR
si cambia algo permanente, o simplemente se cierra aquí si era solo un dato
que corregir.

## Cuándo escribir una

Cuando algo no cuadra entre lo que se dice y lo que el producto hace, o entre
lo que se dice y lo que confirma una fuente externa, y hace falta que alguien
lo revise antes de que se publique o se repita.

## Cómo

1. Nómbrala `INC-NNN-lo-que-pasa-en-una-frase.md`.
2. Añádela al índice de abajo.
3. Cuando se resuelva, marca el estado como **Resuelta** o **Descartada** y,
   si generó una decisión permanente, enlaza la MDR correspondiente.
