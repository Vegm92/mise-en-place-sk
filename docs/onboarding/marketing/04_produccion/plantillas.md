# Plantillas

Formatos listos para copiar. Sirven para dos cosas: ordenarte a ti, y darle a
Claude un molde que rellenar en vez de una hoja en blanco.

## Encargo de pieza de contenido

```markdown
# Encargo: <título provisional>

**Formato:** artículo / email / publicación / página
**Ángulo:** normativa / control de coste / oficio
**A quién:** dueño-chef · grupo · gestoría
**La pregunta que responde:** <una sola, en las palabras del lector>
**Qué quiero que haga después:** <apuntarse / responder / nada, solo confianza>

## Qué tiene que decir
- <idea 1>
- <idea 2>

## Fuentes
- <enlace o documento — obligatorio para toda cifra>

## Qué NO puede decir
- <ver reglas inquebrantables; añade aquí lo específico de esta pieza>

## Entregable
- [ ] Versión española
- [ ] Versión inglesa (si la superficie es bilingüe)
- [ ] Cada dato verificado contra su fuente
```

## Cambio de texto en la app o la landing

Los textos viven dentro del código, así que hay que entregarlos cerrados. Con
esta ficha, el equipo técnico lo aplica sin ida y vuelta.

```markdown
# Cambio de texto

**Dónde:** <pantalla o sección — p. ej. landing, bloque de precios>
**Vista:** móvil / escritorio / ambas

| | Ahora | Propuesto |
|---|---|---|
| Español | <texto actual> | <texto nuevo> |
| Inglés | <texto actual> | <texto nuevo> |

**Por qué:** <una frase>
**Riesgo:** <¿afecta a un precio, a una promesa de producto, a algo legal?>
```

## Guion de entrevista con hostelero

Quince minutos. **Pregunta por lo que ya hace, no por lo que haría.**

```markdown
# Entrevista — <nombre, tipo de local, fecha>

## Calentar
- ¿Qué tipo de local es? ¿Cuánta gente en cocina?
- ¿Cuántos proveedores fijos tienes?

## El recorrido real del papel
- Llega un albarán con la mercancía. ¿Qué pasa con ese papel exactamente?
- ¿Quién lo toca? ¿Dónde acaba?
- ¿Qué le mandas a tu gestor, y cómo?

## El dolor
- La última vez que un proveedor te subió un precio, ¿cómo te enteraste?
- ¿Cuánto tiempo se va en esto a la semana? ¿Quién lo hace?
- ¿Has intentado organizarlo alguna vez? ¿Qué pasó?

## Cerrar
- Si esto se resolviera solo, ¿qué harías con ese tiempo?
- ¿Conoces a alguien más a quien le pase lo mismo?

## Notas
> Cita textual (sus palabras, no tu resumen):
> Sorpresas:
> Qué invalida de lo que creíamos:
```

Las citas textuales son lo más valioso: acaban siendo titulares.

## Ficha de competidor

```markdown
# <Competidor>

**Qué vende:** · **A quién:** · **Precio:** (público / bajo presupuesto)
**Su promesa principal:** <su titular, literal>
**Cómo se vende:** alta sola / demo / comercial
**Qué hace mejor que nosotros:**
**Dónde falla, según sus clientes:**
- <queja + de dónde sale>
**Qué me llevo para nuestro mensaje:**
```

## Cierre de experimento

```markdown
# <Nombre> — <fecha>

**Hipótesis:** creo que <cambio> hará que <métrica> <suba/baje> porque <razón>
**Qué cambié:** · **Cuánto duró:** · **Cuánta gente lo vio:**
**Resultado:** antes X → después Y
**Conclusión:** confirmada / refutada / no concluyente
**Qué hago ahora:**
```

Nota honesta: con el tráfico de una landing pre-lanzamiento, casi todo saldrá
**no concluyente**. Anotarlo igual evita repetir la misma prueba dentro de tres
meses.
